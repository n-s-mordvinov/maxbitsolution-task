# Maxbitsolution Task

Проект представляет собой систему управления кинотеатром с фронтендом на Nuxt.js и бекендом на Express.js.

## Структура проекта

```
.
├── frontend/                 # Nuxt.js фронтенд приложение
├── frontend_technical_task/  # Express.js бекенд API
└── package.json             # Корневой package.json с удобными скриптами
```

## Требования

- Node.js (версия 18 или выше)
- npm (или yarn, pnpm)

## Установка

### Установка всех зависимостей (рекомендуется)

Из корневой директории проекта выполните:

```bash
npm run install:all
```

Эта команда установит зависимости для:
- Корневого проекта
- Фронтенда
- Бекенда

### Установка зависимостей вручную

Если вы предпочитаете устанавливать зависимости отдельно:

```bash
# Установка корневых зависимостей
npm install

# Установка зависимостей фронтенда
cd frontend
npm install

# Установка зависимостей бекенда
cd ../frontend_technical_task
npm install
```

## Запуск приложения

### Запуск всего приложения (фронтенд + бекенд)

Из корневой директории проекта выполните:

```bash
npm run dev
```

Эта команда запустит одновременно:
- Бекенд API на `http://localhost:3022`
- Фронтенд приложение на `http://localhost:3000`

### Запуск компонентов отдельно

#### Запуск только фронтенда

```bash
npm run dev:frontend
```

или из директории `frontend/`:

```bash
cd frontend
npm run dev
```

Фронтенд будет доступен на `http://localhost:3000`

#### Запуск только бекенда

```bash
npm run dev:backend
```

или из директории `frontend_technical_task/`:

```bash
cd frontend_technical_task
npm start
```

Бекенд будет доступен на `http://localhost:3022`

## Доступ к приложению

После запуска приложения:

- **Фронтенд**: [http://localhost:3000](http://localhost:3000)
- **Бекенд API**: [http://localhost:3022](http://localhost:3022)
- **Swagger UI (документация API)**: [http://localhost:3022/api-docs](http://localhost:3022/api-docs)

## Работа с API

### Swagger UI

Бекенд предоставляет интерактивную документацию API через Swagger UI. Для работы с защищенными эндпоинтами:

1. Перейдите на [http://localhost:3022/api-docs](http://localhost:3022/api-docs)
2. Выполните запрос `/login` для получения токена
3. Используйте кнопку "Authorize" для авторизации с полученным токеном

### Изображения

Бекенд также предоставляет статические файлы (постеры фильмов). Изображения доступны по пути:

```
http://localhost:3022/static/images/posters/[имя_файла].jpg
```

Например: `http://localhost:3022/static/images/posters/dark_knight.jpg`

## Важные замечания

⚠️ **Важно**: При перезапуске сервера бекенда все сохраненные данные удаляются. Расписание киносеансов автоматически перегенерируется так, чтобы начинаться с текущего дня.

## Технологический стек

### Фронтенд
- **Nuxt 4** - фреймворк для Vue.js
- **Vue 3** - JavaScript фреймворк
- **Tailwind CSS** - CSS фреймворк
- **Pinia** - управление состоянием
- **Vee-Validate** - валидация форм
- **shadcn-nuxt** - UI компоненты

### Бекенд
- **Express.js** - веб-фреймворк для Node.js
- **JWT** - аутентификация
- **Passport.js** - стратегии аутентификации
- **Swagger** - документация API

## Разработка

Проект использует проксирование запросов на фронтенде. Все запросы к `/api/**` и `/static/**` автоматически проксируются на бекенд (`http://localhost:3022`).

## Проблемы и решение

Если возникают проблемы с запуском:

1. Убедитесь, что порты 3000 и 3022 свободны
2. Проверьте, что все зависимости установлены (`npm run install:all`)
3. Убедитесь, что используете совместимую версию Node.js (18+)
